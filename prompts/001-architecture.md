# Prompt 001 — Architecture

Read `AGENTS.md` and all material under `/docs`.

Do not implement business modules yet.

Produce and review the architecture for:
- application architecture
- database boundaries
- authorization
- audit trail
- electronic signatures
- file storage
- workflow engine
- testing/validation
- future LIMS integration
- future AI assistant

Create/update the architecture documents under `/docs/architecture/`.

Do not claim CAP, CLIA, HIPAA, ISO 15189, or 21 CFR Part 11 compliance merely because a feature exists.

Do not copy proprietary accreditation checklist content or competitor content without appropriate rights.

At completion, run applicable repository checks and report architecture decisions and unresolved risks.
