# PR 12 Validation Boundary

QuickBooks Online provider integration remains development-preview only until a protected release is qualified.

- Railway may use Intuit sandbox credentials only.
- Railway may contain synthetic accounting data only.
- Production access tokens, verifier tokens, customer accounting data, or regulated records are not permitted in preview.
- Protected validation/production credential provisioning and deployment remain governed by the AWS release process.
- This PR does not designate or promote a new validated release candidate.
